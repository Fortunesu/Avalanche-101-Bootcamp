# learn 文件夹

本文件夹用于存放**每位学员的作业**。

## 使用规则

1. **不要修改别人文件夹里的内容。** 每个学员拥有自己以 GitHub 用户名命名的独立文件夹。
2. 提交作业前，请先按 [../Template.md](../Template.md) 的指引，在本目录下创建 `你的GitHub用户名/` 文件夹，并将档案文件命名为 `你的GitHub用户名.md`。
3. 每章课程开课后，将对应的 [../task/taskN.md](../task/) 复制到你的文件夹中完成，然后提交 PR。
4. 任何时间都可以提交作业，但**截止时间之后提交的作业没有奖励**。

## 目录示例

```
learn/
├── README.md          # 本说明文件
├── alice/             # 学员 alice 的文件夹
│   ├── alice.md       # 学员档案（来自 Template.md）
│   ├── task1.md       # 第 1 章作业
│   ├── task2.md       # 第 2 章作业
│   ├── task3.md       # 第 3 章作业
│   └── task4.md       # 第 4 章作业
└── bob/               # 学员 bob 的文件夹
    └── ...
```
